### 🔬 ResearchHub AI — *Flagship Project*
> **Intelligent Research Paper Management System using Agentic AI**

[![TypeScript](https://img.shields.io/badge/TypeScript-61.1%25-007ACC?style=flat-square&logo=typescript)](https://github.com/Vaibhav-dev30/ResearchHub-AI)
[![Python](https://img.shields.io/badge/Python-20.6%25-3776AB?style=flat-square&logo=python)](https://github.com/Vaibhav-dev30/ResearchHub-AI)
[![CSS](https://img.shields.io/badge/CSS-16.1%25-1572B6?style=flat-square&logo=css3)](https://github.com/Vaibhav-dev30/ResearchHub-AI)

A **production-ready full-stack AI system** integrating FastAPI + React (TypeScript) + SQLite + Groq's Llama3. Features modular Agentic AI architecture with JWT authentication, real-time paper analysis, conversational AI, and keyword extraction.

**Key Features:**
- 🔐 Secure JWT-based Authentication with bcrypt hashing
- 🤖 AI-powered Paper Analysis (summarization, key findings, 5 research questions, 10 keywords)
- 💬 Conversational AI Chat powered by Groq Llama3-8b-8192
- 🏗️ Modular AI Agent Architecture (summarizer, keyword extractor, chatbot)
- 🌐 Full REST API with Swagger documentation

```
Stack: FastAPI · React · TypeScript · Groq (Llama3) · SQLite · SQLAlchemy · JWT · Vite
```

### 🖱️ Air Mouse — *Computer Vision Project*
> **Gesture-Controlled Interface — Control Your PC With Hand Movements**

[![Python](https://img.shields.io/badge/Python-99.1%25-3776AB?style=flat-square&logo=python)](https://github.com/Vaibhav-dev30/airmouse)
⭐ **1 Star**

A futuristic, gesture-controlled interface that transforms a webcam into a high-precision input device using computer vision. Features a floating "Antigravity" PyQt5 dashboard with real-time FPS stats and gesture recognition.

**Key Features:**
- 👆 Real-time hand landmark detection using MediaPipe
- 🖱️ Pinch gestures for left/right click, multi-finger scroll
- ⚡ Adaptive smoothing algorithms for low-latency cursor control
- 🚀 Floating semi-transparent HUD dashboard with PyQt5
- 🪟 Cross-platform (Windows/Linux/macOS)

```
Stack: Python · MediaPipe · OpenCV · PyQt5 · Computer Vision
```
